# Flipper FireStick Remote

Bluetooth HID remote for Amazon Fire TV / Fire Stick.

## Controls
- D-pad: navigate
- OK: select
- Back: back
- Hold Up: Home
- Hold Down: Menu
- Hold Left: Rewind
- Hold Right: Fast-forward
- Hold OK: Play/Pause
- Hold Back: exit app

## Build
GitHub Actions builds the app with the official Flipper uFBT action.
After the workflow succeeds, download the `fire-remote-fap` artifact and extract `fire_remote.fap`.
